## Sales And Management Ordering Systems by Adrian (SAMOSA)

An interactive online ordering system prototype. Built for students and school staff to easily order meals, and for canteen staff to organise and manage orders and stock.

## Technologies

- Python
- Tkinter
- SQLite3

## Features

- Customer ordering
- Searching, Filtering and Sorting
- Kitchen order management
- Admin dashboard - Add, delete and update stock
- Secure accounts and passwords.
